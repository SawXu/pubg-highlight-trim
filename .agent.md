# Agent Guidelines

- Do not include sensitive information in code, tests, documentation, logs, CSV summaries, screenshots, PR text, or generated artifacts.
- Sensitive information includes, but is not limited to, IDs of any kind: account IDs, player IDs, user IDs, session IDs, request IDs, thread IDs, clip/source IDs, tokens, keys, credentials, emails, phone numbers, and private local paths.
- Redact real sensitive values with placeholders such as `<redacted>` or replace them with synthetic examples before committing, sharing, or reporting output.

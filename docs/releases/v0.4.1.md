# v0.4.1

`v0.4.0`（Tauri 双安装包管线）之后的一次小版本更新，主要改进图形界面体验与可访问性，CLI 行为不变。

## 图形界面

- 新增常驻任务控制区：任务运行期间可随时查看状态并执行取消等操作，覆盖键盘与屏幕阅读器可访问性（#112）。
- 窗口页脚显示应用版本号。
- 应用图标更新为场记板 + 播放键造型。

## 构建与发布

- 移除已退役的 Rust OCR 构建开关（`scripts/build_windows.ps1`）。
- CLI `--version` 与 UI 版本同步为 `0.4.1`，与 `v0.4.1` 标签一致。

## 升级注意事项

- 无 CLI 参数、报告字段或输出格式变化；可直接覆盖安装。

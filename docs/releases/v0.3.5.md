# v0.3.5

这是 `v0.3.4` 之后的一次 OCR 检测与输出结构更新，重点改进了快速扫描性能、结果缓存、逐段视频归档、跨语言事件识别和 Windows UI 发布包校验。

## 亮点

- 新增可配置的快速 OCR 路径：使用自适应采样，在粗扫描命中目标事件后再对附近时间点进行密集确认，减少无效 OCR 调用。
- 支持持久化 OCR 检测缓存；相同视频和检测配置可复用已有结果，缓存会校验内容指纹、模型及算法版本，并在写入完成后生成校验标记。
- 逐段 Trim 视频统一写入输出根目录下的 `clips/` 子目录，Merge 视频、CSV、摘要和 concat 清单保留在输出根目录，避免视频文件混放。

## CLI 变化

新增或扩展参数：

| 参数 | 说明 |
| --- | --- |
| `--fast-path` / `--no-fast-path` | 启用或禁用自适应低成本采样与持久化 OCR 缓存。 |
| `--cache-dir PATH` | 指定持久化 OCR 结果缓存目录。 |
| `--sampling-mode fixed\|adaptive` | 选择固定扫描计划或粗到细的自适应采样。 |
| `--adaptive-step` / `--adaptive-window` | 设置命中粗扫描目标后，密集采样的间隔和向前搜索窗口。 |
| `--ocr-max-calls` / `--ocr-min-interval` | 限制单个源文件的 OCR 请求次数及未命中缓存请求的最小时间间隔。 |
| `--refine-max-frames` / `--assist-max-frames` | 限制精修和辅助扫描的最大采样帧数。 |
| `--refine-max-seconds` / `--assist-max-seconds` | 限制精修和辅助扫描的墙钟时间预算。 |
| `--brightness-gate-mode full\|light\|none` | 选择完整形态学门控、轻量统计门控或关闭门控。 |

默认行为变化：

- `--output-dir` 现在表示本次运行的输出根目录；所有逐段 Trim 视频写入 `<output>/clips/`。
- Merge 视频默认仍写入输出根目录；显式 `--merge <path>` 继续使用用户指定的路径。
- `--dry-run` / `--scan-only` 只生成扫描记录和摘要，不创建 `clips/` 目录，也不生成 Trim 或 Merge 视频。

## OCR 性能与缓存

- 自适应扫描先使用粗粒度计划发现候选事件，再围绕命中时间点按 `--adaptive-step` 进行密集采样；扫描计划会覆盖优先窗口、候选窗口边界和候选时间锚点。
- 增加 OCR 请求、成功、缓存命中、跳过数量，以及精修 / 辅助预算和终止原因等统计字段，便于通过 CSV、摘要和日志分析运行成本。
- 缓存键包含源视频内容指纹、OCR 模型与算法版本、语言、ROI、扫描 / 精修 / 辅助参数、亮度门控和请求限制等配置；配置变化或缓存标记无效时会自动重新检测。
- 精修和辅助 OCR 可设置帧数及时间预算；同一视频和时间点的主 OCR 与辅助 OCR 复用已读取的帧，减少重复解码。

## 输出与流水线修复

- 修复 Trim 片段输出目录结构：片段文件名仍按序号和事件目标命名，但统一归档到 `clips/` 子目录。
- 覆盖模式会同时清理输出根目录及 `clips/` 中的旧片段；非覆盖模式继续为已存在的输出目录选择唯一名称。
- `summary.json` 记录输出根目录、Merge 文件、concat 清单和 CSV 的实际路径；扫描阶段的候选记录保持稳定列结构并包含运行 ID、缓存状态和门控状态。

## 多语言事件识别

- 中文简体、中文繁体和英文配置补充“因坠落 / 跌落 / 摔落导致击倒或死亡”等 Fall 事件文本，减少不同语言下的漏检。
- 繁体中文补充“多重击杀”文件名提示及对应多杀识别，自动语言检测可覆盖更多 NVIDIA Highlight 文件名变体。

## Windows UI 与发布产物

- Windows UI 的快速扫描模式会向 CLI 传递 `--fast-path`，UI 设置与后端扫描行为保持一致。
- UI 构建流程新增最终压缩包验证：解压后检查 UI exe 和同包 CLI 是否存在，并验证 UI 清单同时声明 `PerMonitorV2` 与 `true/pm` 兼容性。
- 高 DPI 清单验证更加严格，发布前即可发现 UI 可执行文件或同包 CLI 缺失等打包问题。

## 升级注意事项

- 依赖逐段视频路径的脚本需要改为读取 `<output>/clips/`；Merge、CSV、摘要和 concat 清单仍位于输出根目录。
- 需要稳定、可复现扫描时可使用 `--no-fast-path` 或 `--sampling-mode fixed`；资源受限机器可结合 `--ocr-max-calls`、`--refine-max-frames` 等参数设置预算。
- 启用缓存时，请为不同视频处理任务使用可写的 `--cache-dir`；修改 OCR 参数、语言或门控设置后，旧缓存不会被误用。
- 本版本的 Python 包元数据、CLI `--version` 和 UI 项目版本应同步为 `0.3.5`，与 `v0.3.5` 标签一致。
